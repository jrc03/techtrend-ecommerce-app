# TechTrend - Landing Page de E-commerce

Este es el repositorio para la landing page del proyecto TechTrend, una moderna interfaz de e-commerce construida con HTML, CSS y JavaScript, y estilizada con **Tailwind CSS**.

## ✨ Características

-   **Diseño Responsivo**: Se adapta a diferentes tamaños de pantalla, desde móviles hasta escritorio.
-   **Componentes Reutilizables**: Elementos de la interfaz construidos para ser consistentes y fáciles de mantener.
-   **Menú Desplegable Interactivo**: Menú de usuario dinámico para acciones como "Iniciar Sesión" y "Registrarse".
-   **Actualización Automática de Año**: El año en el pie de página se actualiza automáticamente usando JavaScript.

## 🛠️ Tecnologías Utilizadas

-   **HTML5**
-   **CSS3**
-   **JavaScript (ES6+)**
-   **Tailwind CSS**: Un framework de CSS "utility-first" para un desarrollo rápido de UI.
-   **Node.js & npm**: Para la gestión de dependencias y ejecución de scripts.

## 🚀 Cómo Empezar

Sigue estos pasos para configurar y correr el proyecto en tu máquina local.

### Prerrequisitos

Asegúrate de tener [Node.js](https://nodejs.org/) instalado. Puedes verificar tu instalación con:

```bash
node -v
npm -v
```

### Instalación

1.  Clona el repositorio:
    ```bash
    git clone https://github.com/jrc03/techtrend-ecommerce-app.git
    ```
2.  Navega al directorio del proyecto:
    ```bash
    cd "Lab 2- Landing Page"
    ```
3.  Instala las dependencias del proyecto:
    ```bash
    npm install
    ```

### Uso

Para compilar el CSS de Tailwind y observar los cambios en tus archivos, ejecuta el siguiente script desde la terminal:

```bash
npm run build:styles
```

Esto generará el archivo `src/output.css` y lo mantendrá actualizado cada vez que modifiques `src/input.css` o uses clases de Tailwind en tus archivos HTML.

Después de eso, puedes abrir el archivo `src/index.html` en tu navegador para ver la página.
